# VibeStock Domain Model

This document outlines the current conceptual and physical domain models within VibeStock and how they map between system boundaries.

## 1. VibeStock Specific Concepts
The core entity in the system during ingestion and enhancement is `VibeStockProduct`. This lives inside `VibeStock.Ingestor.Cell.Domain`.

### VibeStockProduct
- **Sku (string):** The unique stock keeping unit identifier.
- **Name (string):** The title or name of the product.
- **Description (string):** The raw description provided by the merchant.
- **Price (decimal):** The selling price of the product.
- **Inventory (int):** The available stock quantity.
- **Tags (List<string>):** Raw tags associated with the product.

### Augmentation Fields
- **Intelligence (`ProductIntelligenceReport`):** A complex object containing extracted features, target audience, tone, semantic tags, content gaps, and recommendations. Generated by the `ProductIntelligenceEngine`.
- **SeoFindings (`SeoFinding[]`):** Specific SEO-related issues, scores, and recommendations mapped from the intelligence report.

*Note: Variants are currently represented in a flattened structure where Price and Inventory exist directly on the VibeStockProduct.*

## 2. Generic SaaSFoundry Concepts
VibeStock leverages generic interfaces provided by the SaaSFoundry SDK. These exist to ensure the system is not hard-coupled to specific platforms like Shopify until the very end.

### CommerceProduct (SaaSFoundry.SDK.Commerce)
The abstraction used to represent a product ready for any e-commerce platform.
- **Title**
- **Description**
- **Vendor**
- **Variants (List<CommerceVariant>)**

### CommerceVariant
The abstraction for a specific product variation.
- **Sku**
- **Price**
- **InventoryQuantity**

## 3. Shopify-Specific Concepts
At the `Bridge.Cell` (or Shopify adapter) level, the `CommerceProduct` is translated into Shopify's specific GraphQL representations.

- **GraphQL `productCreate` mutation:** The specific Shopify API call.
- **gid://shopify/Product/{id}:** The external ID format returned by Shopify.
- **userErrors:** Shopify's specific way of returning domain validation errors within GraphQL responses.

## 4. Flow of Concepts
1. **Raw Row:** Dictionary mapping of `string` to `string`.
2. **VibeStockProduct:** Validated domain entity containing product data and subsequently AI-generated Intelligence/SEO findings.
3. **CommerceProduct:** Generic SaaSFoundry entity bridging the system to the commerce adapter.
4. **Shopify GraphQL Mutation:** The platform-specific payload pushed to Shopify.
